# PêchTrack

Pêcher • Suivre • Prospérer. Application de suivi de la pêche artisanale (Saint-Louis, Sénégal).

## Lancer en local

```
npm install
npm run dev
```

Puis ouvrir http://localhost:3000

## Écrans

- Accueil : tableau de bord
- Prises : saisie des prises du jour
- Ventes : enregistrement des ventes
- Dépenses : suivi des dépenses

Les données saisies sont gardées dans le navigateur (localStorage) en attendant une vraie base de données.
